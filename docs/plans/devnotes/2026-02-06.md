### Consistency pass — 8 specification gaps identified and resolved
1. **`||` operator removed** — Founder fallback moved to `founder=` keyword arg on `parent()`, `mother()`, `father()`. Eliminates `|` vs `||` parser precedence ambiguity.
2. **Sibling default scope** — `sibling_mean(X)` defaults to `| FID`. Explicit `|` overrides (e.g., `sibling_mean(X) | mother`).
3. **`parent(X)` = midparent** (average of mother and father) — confirmed intentional.
4. **`noise` vs `cnoise`** — `noise` = univariate, `cnoise` = multivariate (correlated across features, requires tuple LHS). `|` controls sample-level grouping orthogonally. All bare expressions implicitly `| IID`.
5. **ArchComponent registry** — DSL built-in functions organized via base class with `kind` (generative/aggregating/genetic/reference) and `accepts_grouping` metadata.
6. **Effect name resolution** — bare names in formula resolved from `effects={}` dict. Kept simple, no `meta()` wrapper.
7. **Generation 0 documented** — founders skip reproduction, `founder=` fallback kicks in. Future: optionally generate synthetic parent genotypes.
8. **Filter signature** — `filter.apply(generation, phenotype_history, pedigree_history)` accommodates cross-gen and within-gen filters.
