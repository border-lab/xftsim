## Notable Fixes During Testing
- `offspring_per_pair=1` creates all-female offspring (design behavior, not bug) — adjusted test
- `load_simulation_checkpoint` returns dict, not NSimulation — use `NSimulation.from_checkpoint()` instead
- Crossover distribution test needed deterministic het parents to detect switches
- Retention policy prunes gen 0 — tests need `retain_*=10` or iterate over available keys
- Component kind names: 'generative' (not 'noise'), 'aggregating' (not 'aggregation'), 'reference' (not 'parental')
- CNoiseComponent takes `cov=` (not `cov_matrix=`)
- `sim.stop` is a boolean attribute (`sim.stop = True`), not a method (`sim.stop()`)
- MotherComponent: no `inputs=['Y']` on DAG — reads from phenotype_history at runtime, not via DAG edges
- h2 estimation: effects calibrated for standardized genotypes but `standardized_matvec` uses centered-but-unscaled, so h2_realized = h2_design * mean(2pq) / (h2_design*mean(2pq) + noise_var)
- Assortative mating: seed collision between phenotype and mating RNG produces artificially high spouse correlation — use different seeds
