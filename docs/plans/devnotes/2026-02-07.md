## Key Bugs Found & Fixed

1. **DenseHaplotypeArray generation override**: Constructor `generation=0` default overrides SampleMeta.generation. Must pass explicitly.
2. **Retention pruning**: `retain_haplotypes=1` prunes gen 0 after 3 gens — tests relying on gen 0 haplotypes need `n_gen=1`.
3. **Seed determinism**: Sims sharing the same haplotype object diverge due to shared mutable state. Must create independent copies.
