# API reference

## Submodule organization

`xftsim` is organized into a number of submodules, the contents of which are arranged as follows:

| Submodule | Contents |
| --------- | -------- |
| [arch](api_ref/arch) | Phenogenetic architectures and components thereof |
| [effect](api_ref/effect) | Genetic effects |
| [founders](api_ref/founders) | Creating and importing founder haplotypes |
| [index](api_ref/index) | Indices for working with individual-, variant-, and component-level data |
| [io](api_ref/io) | Routines for reading and writing data to disk |
| [mate](api_ref/mate) | Mating regimes and the `MateAssignment` class |
| [ped](api_ref/ped) | Pedigree data structures |
| [proc](api_ref/proc) | Data post-processors (saving intermediate simulation data, limiting memory, etc.) |
| [reproduce](api_ref/reproduce) | Reproduction and transmission of genetic and phenotypic data |
| [sim](api_ref/sim) | Simulation class for setting up and running experiments |
| [stats](api_ref/stats) | Statistical estimators |
| [struct](api_ref/struct) | Basic data structures for working with genotype and phenotype data |
| [utils](api_ref/utils) | Utility functions and profiling |

See individual module pages for detailed API documentation.
